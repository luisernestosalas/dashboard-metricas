# Dashboard de Métricas

Un dashboard moderno y responsivo para visualización de métricas en tiempo real, construido con tecnologías web estándar.

## 🚀 Demo

Puedes ver el dashboard en funcionamiento aquí: [Dashboard Métricas Live](https://dashboard-metricas-4yg4oyk7u-luisernestosalas-2775s-projects.vercel.app)

## 📋 Características

- ✅ **Interfaz moderna y responsive** - Compatible con dispositivos móviles y desktop
- ✅ **Métricas en tiempo real** - Visualización dinámica de datos
- ✅ **Gráficos interactivos** - Representación visual clara de la información
- ✅ **Dashboard limpio** - Diseño minimalista y fácil de usar
- ✅ **Sin dependencias externas** - Construido con HTML, CSS y JavaScript vanilla

## 🛠️ Stack Tecnológico

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Deployment**: Vercel
- **Control de versiones**: Git/GitHub
